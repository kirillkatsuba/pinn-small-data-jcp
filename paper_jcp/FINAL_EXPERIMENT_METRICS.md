# Итоговые результаты экспериментов: mean ± std по трём seed

В каждой строке жирным выделено лучшее среднее значение среди пяти методов. Для `R2` максимум является лучшим; для ошибок, нарушений физических ограничений и времени обучения лучшим является минимум.

Все значения рассчитаны по seed `101`, `102`, `103`. Интерполяция соответствует времени внутри диапазона размеченных данных, экстраполяция — времени после границы обучения.

Для Test 2 в отчёт подставлены classical baselines из усиленного `strong/time-CV` подбора. Tests 3--4 уже содержат этот подбор в итоговых CSV. В Test 1 classical baselines относятся к более раннему standard tuning.
